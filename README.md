A Python program (standard library only, with its own compact 5x7 bitmap typeface stored as row bitmasks and a hand-rolled PNG encoder) that draws a 1024x1024 newspaper poster summing up the world news of Saturday 21 November 2026 — COP31 running into overtime in Antalya with no deal, a Russian missile down in Poland, Anthropic's post-debut slide as the AI sell-off deepens, the strike on Kryvyi Rih, BepiColombo's arrival at Mercury, a banking vendor data breach, and more (see SOURCES.md) — and writes it deterministically to /output/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
